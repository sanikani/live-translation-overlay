# 실시간 다국어 번역 자막 Overlay

다문화 학부모 교육을 위해 **강사의 발표 음성을 실시간으로 인식하고, 여러 언어로 번역한 뒤 PowerPoint·PDF·웹 브라우저 등 기존 강의자료 위에 자막으로 표시하는 Windows용 프로그램**입니다.

> MVP의 목표는 **코딩을 전혀 모르는 강사도 프로그램을 실행하고, 마이크와 번역 언어만 선택한 뒤 바로 사용할 수 있는 것**입니다.

---

## 1. 프로젝트 목표

강사가 한국어로 발표하면 프로그램이 아래 과정을 자동으로 처리합니다.

```text
강사 음성
   ↓
마이크 입력
   ↓
실시간 음성 인식(STT)
   ↓
한국어 문장 확정
   ↓
여러 언어로 동시 번역
   ↓
강의자료 위 자막 Overlay
```

예시:

```text
강사: "다음 주 금요일까지 신청서를 제출해 주세요."

EN  Please submit the application by next Friday.
ZH  请在下周五之前提交申请表。
VI  Vui lòng nộp đơn đăng ký trước thứ Sáu tuần sau.
TH  กรุณาส่งใบสมัครภายในวันศุกร์หน้า
```

## 2. MVP 핵심 기능

첫 번째 버전에서는 아래 기능에만 집중합니다.

### 포함

- 노트북 또는 외부 마이크 선택
- 한국어 발표 음성 실시간 인식
- 확정된 문장 단위 번역
- 여러 언어 동시 번역
- 번역 언어 선택
- PowerPoint, PDF, 웹 브라우저 등 다른 프로그램 위에 자막 표시
- Always On Top 반투명 자막창
- 자막 글자 크기 조절
- 자막 위치 조절
- 번역 시작 / 종료
- 자막 지우기

### 초기 테스트 언어

- 영어
- 중국어
- 베트남어
- 태국어

번역 API 지원 범위에 따라 이후 일본어, 몽골어, 러시아어, 우즈베크어, 인도네시아어 등으로 확장합니다.

## 3. MVP에서 제외

초기 범위를 작게 유지하기 위해 아래 기능은 이후 버전으로 미룹니다.

- 회원가입 / 로그인
- 별도 백엔드 서버
- 데이터베이스
- QR 코드 접속
- 학부모 스마트폰 자막
- 강의 녹음 및 저장
- 강의 AI 요약
- 학교 용어 사전
- PPT / PDF 내용 분석
- 학부모 질문 역방향 번역
- 번역 결과 저장
- 관리자 페이지

MVP에서는 **한 대의 Windows PC 안에서 음성 인식, 번역, 자막 표시까지 처리**합니다.

## 4. 사용자가 실제로 보는 화면

코딩이나 프로그램 설정을 모르는 강사를 기준으로 최대한 단순하게 구성합니다.

```text
┌──────────────────────────────┐
│      실시간 번역 자막       │
│                              │
│ 발표 언어                    │
│ [ 한국어              ▼ ]   │
│                              │
│ 마이크                       │
│ [ 기본 마이크          ▼ ]   │
│                              │
│ 번역 언어                    │
│ ☑ English                    │
│ ☑ 中文                       │
│ ☑ Tiếng Việt                 │
│ ☐ ภาษาไทย                    │
│                              │
│       [ 번역 시작 ]          │
└──────────────────────────────┘
```

사용 순서는 다음과 같습니다.

1. 프로그램 실행
2. 사용할 마이크 선택
3. 필요한 번역 언어 선택
4. **번역 시작** 클릭
5. 평소처럼 PowerPoint 또는 강의자료 실행
6. 화면 하단에 실시간 번역 자막 표시
7. 강의 종료 후 **번역 종료** 클릭

API, 서버, STT, 번역 모델 같은 기술 용어는 사용자 화면에 노출하지 않습니다.

## 6. MVP 기술 구성

초기 버전은 별도 서버 없이 Python 데스크톱 애플리케이션 하나로 구현합니다.

| 역할 | 기술 |
| --- | --- |
| 프로그램 언어 | Python |
| 데스크톱 UI | PySide6 |
| 음성 인식 | Azure Speech-to-Text 우선 검토 |
| 번역 | Azure Translator 우선 검토 |
| 자막창 | PySide6 Transparent / Always-on-top Window |
| 서버 | 없음 |
| 데이터베이스 | 없음 |
| 배포 | Windows 실행 파일(.exe) |

### Python + PySide6를 선택하는 이유

MVP의 목표는 복잡한 시스템 구축이 아니라 실제 강의에서 사용할 수 있는 프로그램을 빠르게 검증하는 것입니다.

- 서버 운영이 필요 없음
- Windows 데스크톱 UI를 비교적 빠르게 구현 가능
- 투명한 Always-on-top 자막창 구현 가능
- 음성 및 번역 SDK 연동이 쉬움
- 최종적으로 사용자가 Python을 설치하지 않아도 `.exe`로 배포 가능

## 9. 실시간 번역 처리 방식

음성 인식기는 사용자가 말을 끝내기 전에도 중간 결과를 계속 생성합니다.

예를 들어:

```text
"오늘은 학교생활에 대해서 설명하겠습니다."
```

중간 결과가 아래처럼 바뀔 수 있습니다.

```text
오늘은
오늘은 학교생활에
오늘은 학교생활에 대해서
오늘은 학교생활에 대해서 설명하겠습니다
```

이 중간 결과를 전부 번역하면 자막이 계속 바뀌고 API 호출도 불필요하게 증가합니다.

따라서 MVP에서는:

```text
음성 입력
   ↓
중간 STT 결과
   ↓
문장 확정 여부 확인
   ↓
확정된 문장만 번역
   ↓
여러 언어 자막 표시
```

방식을 사용합니다.

목표 지연 시간은 **약 1~2초 수준**으로 잡습니다.

완벽한 동시통역보다 **읽기 쉬운 안정적인 자막**을 우선합니다.

## 10. Overlay 요구사항

자막창은 강의자료 위에 자연스럽게 올라가야 합니다.

필수 조건:

- Always On Top
- 창 테두리 제거
- 반투명 배경
- 화면 하단 또는 상단 선택
- 큰 글씨
- 언어별 줄 분리
- PowerPoint 발표 모드에서도 유지
- 가능하면 Click-through 지원

초기에는 화면 하단 약 20~30%를 자막 영역으로 사용합니다.

## 11. 개발 단계

### Phase 1. 마이크 → 한국어 STT

목표:

```text
강사가 말함
→
화면에 한국어 문장이 표시됨
```

완료 기준:

- 마이크 선택 가능
- 한국어 음성 인식 가능
- 확정된 문장 확인 가능
- 30분 이상 지속 실행 시 오류 없이 동작

### Phase 2. 한국어 → 영어 번역

목표:

```text
"다음 주까지 신청해주세요."
→
"Please apply by next week."
```

완료 기준:

- 확정된 STT 문장을 번역 API로 전달
- 영어 번역 결과 출력
- 중복 번역 요청 방지

### Phase 3. 다국어 동시 번역

목표:

```text
한국어
   ├─ English
   ├─ Chinese
   ├─ Vietnamese
   └─ Thai
```

완료 기준:

- 여러 언어 선택 가능
- 선택된 언어만 번역
- 특정 언어 번역 실패가 전체 자막을 중단시키지 않음

### Phase 4. 자막 Overlay

목표:

PowerPoint, PDF 등의 강의자료 위에 번역 결과를 표시합니다.

완료 기준:

- 항상 위에 표시
- 반투명 배경
- 전체화면 PowerPoint 위에서도 표시
- 자막 위치 조절
- 글자 크기 조절

### Phase 5. 실제 사용자용 UI

완료 기준:

- 마이크 선택
- 언어 선택
- 번역 시작
- 번역 종료
- 글자 크기 조절
- 자막 위치 선택
- 자막 지우기

기술 용어는 사용자 화면에서 제거합니다.

### Phase 6. 실제 강의 테스트

테스트 항목:

- 30분 이상 연속 사용
- 1시간 이상 연속 사용
- 발표자가 PC에서 멀어지는 상황
- 교실 소음이 존재하는 상황
- PowerPoint 페이지 전환
- 여러 언어를 동시에 선택한 상황
- 인터넷 연결이 일시적으로 느려진 상황
- API 호출 실패 후 복구

MVP 완료 기준은 **실제 발표 환경에서 30분 이상 안정적으로 사용할 수 있는 것**입니다.

## 12. 비용 계획

MVP는 서버와 데이터베이스를 사용하지 않기 때문에 고정 운영비가 거의 없습니다.

| 항목 | 예상 비용 |
| --- | ---: |
| Python | 무료 |
| PySide6 | 무료로 개발 시작 가능 |
| VS Code | 무료 |
| 서버 | 0원 |
| DB | 0원 |
| 도메인 | 0원 |
| Windows 실행 파일 생성 | 무료 도구 사용 가능 |

초기에는 Azure 무료 사용 구간을 활용해 개발 및 소규모 테스트 비용을 최소화합니다.

실제 유료 사용 시 비용은 다음 요소에 따라 증가합니다.

- 강의 시간
- 실제 발화 시간
- 번역 문자 수
- 동시에 사용하는 번역 언어 수

번역 언어가 늘어나도 한국어 STT는 한 번만 수행합니다.

```text
한국어 음성
   ↓ STT 1회
한국어 텍스트
   ↓
   ├─ 영어 번역
   ├─ 중국어 번역
   ├─ 베트남어 번역
   └─ 태국어 번역
```

따라서 언어 수 증가에 따른 추가 비용은 주로 번역 API에서 발생합니다.

> 클라우드 API 가격은 변경될 수 있으므로 실제 배포 전 공식 가격표를 다시 확인합니다.

## 14. MVP 이후 확장 계획

MVP의 실제 사용성을 검증한 뒤 순차적으로 확장합니다.

### 1단계: 학교 환경 특화

- 학교 및 교육 용어 사전
- 자주 사용하는 표현 등록
- 사용자 지정 번역 용어

### 2단계: 강의자료 Context 활용

- PowerPoint / PDF 텍스트 추출
- 현재 슬라이드 내용 분석
- 현재 발표 주제를 STT 및 번역 Context로 활용
- 교육 전문 용어 인식 정확도 향상

### 3단계: 학부모 개인 자막

- 강의 화면 QR 코드
- 학부모 스마트폰 웹 접속
- 개인별 원하는 언어 선택
- 프로젝터에는 주요 2~3개 언어만 표시

### 4단계: 양방향 번역

- 학부모 스마트폰 질문
- 학부모 언어 → 한국어 번역
- 강사 한국어 답변 → 학부모 언어 번역

### 5단계: 강의 종료 후 지원

- 강의 Transcript
- AI 요약
- 중요 일정 자동 추출
- 준비물 / 제출기한 자동 추출
- 언어별 학부모 안내문 생성

## 15. 개발 원칙

### 사용자는 개발자가 아니다

사용자가 API Key, 서버 주소, 모델 이름 등을 알 필요가 없어야 합니다.

### 기능보다 안정성을 우선한다

초기에는 지원 언어 수보다 실제 강의에서 안정적으로 동작하는 것을 우선합니다.

### 완벽한 동시통역보다 읽을 수 있는 자막을 만든다

중간 STT 결과를 모두 번역하기보다 문장이 확정된 뒤 번역하여 자막 흔들림을 줄입니다.

### MVP에서는 서버를 만들지 않는다

서버가 꼭 필요한 기능이 생기기 전까지 한 대의 PC에서 모든 기능을 처리합니다.

## 16. 첫 번째 릴리스 목표

> **강사가 프로그램을 실행하고 번역 언어를 선택한 뒤 PowerPoint 발표를 시작하면, 강사의 한국어 발표가 영어·중국어·베트남어 등 선택한 여러 언어로 실시간 번역되어 강의자료 위에 자막으로 표시된다.**

이 기능이 실제 교실에서 안정적으로 동작하면 MVP를 완료한 것으로 판단합니다.

현재 **Phase 4까지 코드 구현 완료, 실제 Windows/Azure/PowerPoint 환경 검증 전** 상태입니다.

### Phase 1 - 마이크 → 한국어 STT

- [x] Azure Speech SDK 연동
- [x] 한국어 연속 음성 인식
- [x] 중간 인식 결과 / 확정 문장 분리
- [x] 마이크 선택
- [x] 시작 / 중지
- [ ] 실제 Windows 기본 마이크 검증
- [ ] 외부 마이크 검증
- [ ] 30분 이상 연속 테스트

### Phase 2 - 한국어 → 영어 번역

- [x] Azure Translator REST API 연동
- [x] 확정된 문장만 번역
- [x] 번역 호출을 UI 스레드와 분리
- [x] 번역 오류 시 STT 계속 실행
- [ ] 실제 Azure 호출 검증
- [ ] 실제 지연 시간 측정

### Phase 3 - 다국어 동시 번역

- [x] 영어 선택
- [x] 중국어(간체) 선택
- [x] 베트남어 선택
- [x] 태국어 선택
- [x] 필요한 언어만 체크박스로 선택
- [x] 한 문장을 여러 대상 언어로 한 번에 요청
- [x] 언어별 번역 결과 분리
- [x] 번역 기록 표시
- [ ] 실제 4개 언어 동시 번역 검증

Azure Translator의 다중 대상 번역 기능을 사용하므로 선택한 언어마다 요청을 따로 보내지 않고, 한 문장에 대해 여러 `to` 값을 하나의 요청에 전달합니다.

### 현재 사용자 흐름

```text
프로그램 실행
   ↓
마이크 선택
   ↓
번역 언어 선택
   ↓
자막을 띄울 화면 선택
   ↓
상단 / 하단 및 글자 크기 설정
   ↓
실시간 번역 시작
   ↓
PowerPoint / PDF 발표
   ↓
확정된 한국어 문장
   ↓
선택한 여러 언어로 동시 번역
   ↓
강의자료 위 Overlay
```

실행 방법은 [docs/SETUP.md](docs/SETUP.md)를 참고합니다.

### 다음 단계

기능 구현 관점에서는 MVP의 핵심 흐름이 연결되었습니다. 다음은 기능 추가보다 **실제 Windows 환경 검증과 사용성 수정**이 우선입니다.

검증 후 필요하면 다음 순서로 확장합니다.

1. Windows 실행 파일(.exe) 패키징
2. 학교 / 교육 용어 사전
3. PPT / PDF 내용을 활용한 번역 Context
4. QR 기반 학부모 개인 자막
5. 학부모 → 강사 역방향 번역
